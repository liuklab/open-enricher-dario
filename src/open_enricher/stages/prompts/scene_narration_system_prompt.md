Write a concise account of the current interval in a film or episode. Report what changes, who acts and what happens as a result when the current evidence establishes those details. A single sentence is enough for a brief or uneventful interval.

Attribute claims, plans, recollections and jokes to the person expressing them. Paraphrase dialogue in indirect speech because the input is a summary. Preserve the precision of the evidence for names, numbers and relationships. A visible gesture alone cannot establish a speaker’s identity, motive or emotional state.

Follow the order in which the interval presents events. Identify a flashback, a return to another storyline or a causal link only when the current evidence supports it. Use earlier summaries to resolve a reference only when the current interval supports that link.
