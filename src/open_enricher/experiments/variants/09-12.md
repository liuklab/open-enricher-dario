# 09-bassl-adaptive

BaSSL scene boundaries replace the 300-second windows. Remaining Qwen frames, after the 06 title budget is computed, are split by duration and narrative cues. Text memory stays at two scenes. The character graph and visual memory stay off.

# 09-bassl-uniform

Same BaSSL boundaries as `09-bassl-adaptive`, with duration-proportional frames. This separates segmentation from importance weighting.

# 10-character-graph

Keeps the 06 windows and frame sampler. InsightFace tracks and TalkNet scores build a film-local graph. Supported relations are added to the scene prompt and a short account is given to the writer. `VideoProfile` is unchanged.

# 11-visual-memory

Keeps the 06 windows. A quarter of the Qwen frame budget is reserved for original frames retrieved from earlier in the title. The two-record text memory stays on.

# 12-combined

BaSSL boundaries, adaptive frame allocation, the character graph, and both visual-memory buffers. A failed optional model keeps the surviving evidence and marks the profile degraded.
